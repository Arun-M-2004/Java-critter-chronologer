# Critter Chronologer

A Java backend application for managing pets, owners, employees, schedules, and pet-care services.

## Overview

Critter Chronologer provides REST APIs for managing information about pets, customers, employees, and scheduled services. The project demonstrates backend development, object-oriented programming, REST API design, data persistence, and automated testing.

## Technologies

- Java 17
- Spring Boot
- Maven
- REST APIs
- H2 Database
- JUnit
- Git & GitHub

## Features

- Manage pet and owner information
- Manage employee information and skills
- Schedule pet-care services
- Find employees based on service requirements and availability
- RESTful API endpoints
- Automated functional testing

## Testing

The project includes automated functional tests covering major application features.
